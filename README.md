# Jan Oberle – Webdesign

Portfolio-Website mit drei Demo-Projekten, gehostet über GitHub Pages.

| Seite | Pfad | Sprache |
|---|---|---|
| Portfolio | `/` | DE / ES / EN (Umschalter, oder `#de`, `#es`, `#en` an die URL hängen) |
| Fuego Lento – Parrilla (Demo) | `/fuego-lento/` | ES |
| Navaja Club – Barbería (Demo) | `/navaja-club/` | ES |
| Farbwerk – Malermeister (Demo) | `/farbwerk/` | DE |

Alle Seiten sind statisches HTML ohne Build-Schritt. Die Demo-Betriebe sind fiktiv.

**Veröffentlichen:** Settings → Pages → Source „Deploy from a branch“ → `main` / `/ (root)`.
